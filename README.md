# Despacho · descargas

Instaladores y archivos de actualización de Despacho. Aquí no hay código.

- **Descargar la última versión (Windows):** [Despacho-setup.exe](https://github.com/excommerceba-hub/despacho-descargas/releases/latest/download/Despacho-setup.exe)
- Todas las versiones: [Releases](https://github.com/excommerceba-hub/despacho-descargas/releases)

`estable/latest.json` y `pruebas/latest.json` son los manifiestos que consulta Despacho para actualizarse. Los instaladores van firmados con la clave de actualizaciones del proveedor: Despacho rechaza cualquier otro.
